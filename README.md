# Мини-Склад

Учебная конфигурация 1С:Предприятие с минимальным контуром складского учёта.
Цель — понять базовые механизмы: справочники, документы, движения по регистрам,
формы, подсистемы, командный интерфейс и программную фильтрацию данных.

## Состав конфигурации

### Справочники

**Товары** (иерархический — опционально)

| Реквизит | Тип | Назначение |
|---|---|---|
| Наименование | Строка | Идентификация номенклатуры |
| Единица измерения | Справочник «ЕдиницыИзмерения» | Количество в движениях |
| Цена продажи | Число (15.2) | Автоподстановка в «Реализацию» |

**Контрагенты**

| Реквизит | Тип | Назначение |
|---|---|---|
| Наименование | Строка | Идентификация в документах |
| ТипКонтрагента | Перечисление (ЭтоПоставщик, ЭтоПокупатель, ПоставщикИПокупатель) | Фильтрация выбора в документах |

### Перечисления

- **ТипКонтрагента**: ЭтоПоставщик, ЭтоПокупатель, ПоставщикИПокупатель.

### Документы

**Поступление**
- Шапка: Поставщик (тип = Поставщик или ПоставщикИПокупатель), Дата, Номер.
- Табличная часть «ПоступаемыеТовары»: Товар, Количество, Цена, Сумма.
- Движения: приход по регистру накопления «ОстаткиТоваров».

**Реализация**
- Шапка: Покупатель (тип = Покупатель или ПоставщикИПокупатель), Дата, Номер.
- Табличная часть «ПродаваемыеТовары»: Товар, Количество, Цена, Сумма.
- Движения: расход по регистру накопления «ОстаткиТоваров».

### Регистры накопления

- **ОстаткиТоваров** — измерения: Товар; ресурс: Количество.

### Подсистема и интерфейс

Подсистема **«МиниСклад»** включает:
- справочники «Товары», «Контрагенты»;
- документы «Поступление товаров», «Реализация товаров»;
- отчёт «Остатки товаров».

В свойствах подсистемы (вкладка **«Командный интерфейс»**) настроен вывод команд на панель навигации и панель действий.

## Программная фильтрация контрагентов по двум типам

Штатный механизм «Связи параметров выбора» позволяет фильтровать только по **одному** значению перечисления. Для выбора двух типов (например, «Поставщик» и «ПоставщикИПокупатель») используется программный отбор через событие `НачалоВыбора`.

### Особенности реализации

1. **Клиентский контекст (8.2 и выше)** не позволяет напрямую обращаться к менеджерам перечислений (возникает ошибка «Переменная не определена (Перечисления)»).
2. **Решение:** создание массива значений вынесено в серверную функцию `&НаСервереБезКонтекста`, которая возвращает клиенту готовый массив.
3. **Программный отбор:** Платформа 1С позволяет передавать отбор по реквизитам справочника при открытии формы выбора. Достаточно передать структуру с ключом `"ТипКонтрагента"` и массивом значений.

### Пример кода (из формы документа)


	&НаКлиенте
	Процедура ПоставщикНачалоВыбора(Элемент, ДанныеВыбора, ВыборДобавлением, СтандартнаяОбработка)
		
		СтандартнаяОбработка = Ложь;
		
		// Вызываем серверную функцию для получения массива
		МассивТипов = ПолучитьМассивТиповПоставщиков();
		
		ПараметрыОтбора = Новый Структура;
		ПараметрыОтбора.Вставить("ТипКонтрагента", МассивТипов);
		
		ПараметрыФормы = Новый Структура("Отбор", ПараметрыОтбора);
		ОткрытьФорму("Справочник.Контрагенты.ФормаВыбора", ПараметрыФормы, Элемент);
		
	КонецПроцедуры
	
	&НаСервереБезКонтекста
	Функция ПолучитьМассивТиповПоставщиков()
		
		МассивТипов = Новый Массив;
		МассивТипов.Добавить(Перечисления.ТипКонтрагента.ЭтоПоставщик);
		МассивТипов.Добавить(Перечисления.ТипКонтрагента.ПоставщикИПокупатель);
		
		Возврат МассивТипов;
		
	КонецФункции


Расчёт сумм в табличной части
Логика расчёта вынесена в отдельные процедуры, чтобы избежать дублирования кода и ошибок при вводе данных в произвольном порядке.

Правила:

При изменении Цены или Количества — пересчитывается Сумма.

При изменении Суммы — пересчитывается Цена (только если Количество ≠ 0). После пересчёта цены сумма пересчитывается заново, чтобы избежать расхождений из-за округления.

	     #Область РасчетТабличнойЧасти
	
	&НаКлиенте
	Процедура ПродаваемыеТоварыЦенаПриИзменении(Элемент)
		РассчитатьСуммуВСтроке();
	КонецПроцедуры
	
	&НаКлиенте
	Процедура ПродаваемыеТоварыКоличествоПриИзменении(Элемент)
		РассчитатьСуммуВСтроке();
	КонецПроцедуры
	
	&НаКлиенте
	Процедура ПродаваемыеТоварыСуммаПриИзменении(Элемент)
		РассчитатьЦенуИзСуммы();
	КонецПроцедуры
	
	#КонецОбласти
	
	#Область ВспомогательныеПроцедуры
	
	&НаКлиенте
	Процедура РассчитатьСуммуВСтроке()
		ТекущаяСтрока = Элементы.ПродаваемыеТовары.ТекущиеДанные;
		Если ТекущаяСтрока <> Неопределено Тогда
			ТекущаяСтрока.Сумма = ТекущаяСтрока.Цена * ТекущаяСтрока.Количество;
		КонецЕсли;
	КонецПроцедуры
	
	&НаКлиенте
	Процедура РассчитатьЦенуИзСуммы()
		ТекущаяСтрока = Элементы.ПродаваемыеТовары.ТекущиеДанные;
		Если ТекущаяСтрока <> Неопределено Тогда
			Если ТекущаяСтрока.Количество <> 0 Тогда
				ТекущаяСтрока.Цена = ТекущаяСтрока.Сумма / ТекущаяСтрока.Количество;
				ТекущаяСтрока.Сумма = ТекущаяСтрока.Цена * ТекущаяСтрока.Количество;
			Иначе
				ТекущаяСтрока.Цена = 0;
			КонецЕсли;
		КонецЕсли;
	КонецПроцедуры
	
	#КонецОбласти

Запуск
Открыть конфигуратор 1С:Предприятие.

Загрузить конфигурацию из src/ (или развернуть из .cf/.cfе).

Обновить конфигурацию базы данных (F7).

Запустить 1С:Предприятие (F5), открыть подсистему «МиниСклад».
